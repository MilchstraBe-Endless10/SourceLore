## 三、UI 侧卡在哪（诚实记录）

### 已查清的事实

1. **Tobs 官方扩展点 = `dockPanels`**
   ```js
   ctx.provide("dockPanels", dockPanels)
   dockPanels.register(createMarketPanel(...))  // 内置插件市场就这么注册的
   ```
   panel 契约：`{id,title,icon,scope:"global",order,defaultPosition,component,headerAction}`
   id 正则 `/^[a-zA-Z0-9:@._-]{1,160}$/`，禁 `instance:` 前缀，返回 dispose

2. **`dockPanels` 是浏览器侧服务，宿主看不到**
   宿主或 client 的 `exports.inject` 声明它 → 插件永久
   `pending (waiting for service: dockPanels)` → 整个插件不挂载。
   **两处 inject 都必须留 `[]`**（index.js + client.js，都改过了）

3. **client.js 热加载有效**
   rev 变化 = 已加载。`curl -sN http://127.0.0.1:<port>/plugins/events | grep sourcelore`
   当前 rev `e2eadb286117`

4. **`@botharness/ui` 补丁是错的路**
   Tobs 11-11 19:57 升 1.6.1，md5 `f12479a2`→`1f71cba1`，补丁全丢。已回滚原版。
