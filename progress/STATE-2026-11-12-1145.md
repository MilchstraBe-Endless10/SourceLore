## 11:46 补充：computer-use 加载失败的确切原因已定位

日志原文（`~/.config/open-deepseek-harness-desktop/logs/harness.log`，
时间 2026-11-11T19:50:18.971Z）：

```
community-desktop.experimental.computer-use (@deepseek-ai/dsh-computer-use):
  Error: service "computerUse" has been registered at <ComputerUseRegistry>
community-desktop.experimental.computer-use-provider
  (@deepseek-ai/dsh-experimental-computer-use-cua-driver-native):
  Error: computer use provider "b..." 
```

**这是重复注册冲突。** `cordis.patch.yml` 第 40-43 行的 `- insert:` 段把这两个包
再注册了一次，而运行时已经内置注册过同一个 service。

### 修法（需要重启才生效）

从 `$DSH_HOME/profiles/web/cordis.patch.yml` 删掉这一段：

```yaml
- insert:
    - id: community-desktop.experimental.computer-use
      name: '@deepseek-ai/dsh-computer-use'
    - id: community-desktop.experimental.computer-use-provider
      name: '@deepseek-ai/dsh-experimental-computer-use-cua-driver-native'
```

然后重启 DSH。重启后 agent 会拿到 computer 工具，点击/截图问题彻底消失。

**为什么没做**：改 cordis.patch.yml 属宿主配置，必须重启 DSH 才生效，
而"未经明示同意不得重启 DSH"是硬规则（MEMORY.md 里记了两条）。
