# 事故记录：DSH 主界面内容区变空（2026-11-12 15:21）

## 现象
DSH 桌面窗口左侧栏正常，右侧内容区全白（约 231KB 截图，之前正常约 1.1MB）。
点击左侧会话条目（Tobs / uu）无反应。

## 我做了什么才导致的
在 `plugin/dsh-sourcelore-cards/client.js` 里加了一段 **DOM 点击兜底**：

```js
var rail = document.querySelector(".bh-workspace-rail") || document.body;
var nodes = rail.querySelectorAll("button, [role=button], a, div");
for (...) {
  if (txt === "Bot 模式") { el.click(); return; }
}
```

`.bh-workspace-rail` 是 **Tobs 自己的**侧栏类名，但 DSH 主界面也有一个同名容器
（或 `document.body` 兜底命中），于是这段代码点了 DSH 外壳的某个元素，
把内容区切成了空面板。

## 已做的回滚
已经从 client.js 删除整个 `autoEnterBotMode()` 及其调用，`node --check` 通过，
rev 变为 `a85d334a6884`（热加载已生效）。
**但界面没有自动恢复** —— 因为空白是 DSH 外壳的 UI 状态，插件回滚不回滚它。

## 恢复办法（按顺序试）
1. 点左侧任一会话（如 Tobs / uu / 某条历史会话）→ 应切回对话视图
2. 若点击无效：切换依赖页签（对话/视台/日记/轨迹/Swarm）
3. 若仍空：`Ctrl+R` 或 `Ctrl+Shift+R` 刷新页面（Electron 内）
4. 最后手段：重启 DSH（需用户同意）

## 教训（要写进 AGENTS.md）
- **客户端插件里绝对不要用 `document.querySelectorAll("div")` 之类宽泛选择器去 click**。
  DSH 外壳与 Tobs 共享 DOM，误伤面太大。
- 想进 Bot 模式，只能用官方语义入口（`ctx.layout.selectPanel`），拿不到就**如实报告**，
  不要写 DOM hack 去猜。
- 给客户端的自动操作必须先限定在**自己的面板容器**内，且要有幂等与失败静默。
